# Tilak Nagar Civic Pulse

## Resident Satisfaction Analytics for Local Government Services

This project studies residents' satisfaction with important local services in Tilak Nagar, Mumbai.

## Project Objectives

- Measure resident satisfaction with local services.
- Identify services that need improvement.
- Analyse residents' suggestions.
- Present findings using charts, Power BI and Streamlit.

## Services Covered

- Water supply
- Garbage collection
- Public cleanliness
- Roads and footpaths
- Street lighting
- Drainage and sewage
- Public toilets
- Online municipal services

## Tools Used

- Google Forms
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Power BI
- Streamlit
- GitHub

## Project Workflow

1. Collect survey responses through Google Forms.
2. Store the original CSV in the raw data folder.
3. Clean the data using Pandas.
4. Analyse satisfaction ratings.
5. Create charts and a Power BI dashboard.
6. Display findings through a Streamlit website.
7. Prepare recommendations for local service improvement.

## Current Status

Survey data collection is currently in progress. Final results will be added after collecting sufficient genuine responses.

## Privacy Note

Raw survey responses and personal information will not be published. Only anonymised processed data will be used for analysis and presentation.

## Limitation

The findings will represent only the surveyed participants and will not represent the entire population of Mumbai.
